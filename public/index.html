About

About Me

I'm a full-stack developer who builds complete web applications on my own: the interface people use, the server and database behind it, and the deployment that keeps it online. Building the four projects below taught me how real products work, from user accounts and security to live video calls.

What I've learned by building them

Front to Back

Interfaces, API routes, serverless functions and scheduled jobs, built as one app.

Databases

Relational schemas built step by step with migrations, access rules on every row, and data that syncs live.

Security

Logins and sessions, rate limiting, protection against request forgery, and secret keys kept off the browser.

Real-Time

Live updates, WebSocket data streams that reconnect on their own, and peer-to-peer video calls.

Files & Documents

Image compression in the browser, private file storage, PDF generation and ZIP exports.

Integrations

Third-party APIs, maps and routing, email sending, browser notifications and two-language interfaces.
